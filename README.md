# SongRyeon-life

정보 리스트가 연산자를 선택하고, 실행 결과가 다시 정보와 이후 작동에 영향을 주는 작은 Python 실험입니다. 사용자의 설계를 바탕으로 AI와 함께 구현하며, 코딩을 배우면서 구조를 탐구합니다.

현재는 교류를 한 번 실행하는 초기 프로토타입입니다. 학습 알고리즘이나 언어 능력은 아직 구현하지 않았으며, 의식이나 퀄리아를 입증한 시스템이 아닙니다.

## 실행

Python 3을 사용하며 외부 패키지는 필요하지 않습니다. 개발 과정에서는 Python 3.12에서 실행을 확인했습니다.

```sh
git clone https://github.com/Junghoo09/SongRyeon-life.git
cd SongRyeon-life
python interaction.py
```

예상 출력:

```text
교류 전: [0, 4, 5, 0, 1, 0]
교류 후: [1, 4, 5, 0, 1, 0]
```

한 번 실행하고 종료합니다. 변경된 리스트는 메모리에만 남으므로 프로그램을 다시 실행하면 초기값부터 시작합니다.

## 파일과 역할

| 파일 | 역할 |
| --- | --- |
| `informations.py` | 정보 리스트와 학습에서 조정할 별도의 교류 리스트 |
| `operator.py` | 계산 함수, 교류 함수, 함수 등록 목록 |
| `interaction.py` | 프로젝트의 함수를 불러와 교류 한 번 실행 |

```python
operators = [add, subtract]
interaction_operators = [interaction]
```

첫 목록은 계산 연산자, 두 번째 목록은 교류 연산자를 담습니다. 목록의 번호는 실제 메모리 주소가 아니라 함수를 선택하는 인덱스입니다.

## 정보가 움직이는 순서

정보와 교류 설정을 두 리스트로 분리합니다. 학습 대상으로 정한 것은 `interaction_list`의 네 값이며, 학습 알고리즘은 아직 구현하지 않았습니다.

```python
first_information = [0, 4, 5, 0, 1, 0]
interaction_list = [0, 1, 2, 3]
```

1. 교류 리스트의 네 값 `0, 1, 2, 3`을 정보 리스트에서 설정을 읽을 위치로 사용합니다.
2. 정보 위치 `0`에서 연산자 번호 `0`을 읽어 `add`를 고릅니다.
3. 정보 위치 `1`의 값 `4`를 이용해 정보 위치 `4`에서 `x = 1`을 읽습니다.
4. 정보 위치 `2`의 값 `5`를 이용해 정보 위치 `5`에서 `y = 0`을 읽습니다.
5. 정보 위치 `3`에서 결과를 쓸 위치 `0`을 읽습니다.
6. `add(1, 0, 0)`이 `(0, 1)`을 반환합니다.
7. 정보 위치 `0`을 `1`로 바꿉니다. 같은 리스트로 다시 교류하면 `subtract`가 선택됩니다.

교류 리스트를 `[0, 2, 1, 3]`으로 바꾸면 `x`와 `y`를 읽는 연결이 서로 바뀝니다. 현재 실행은 정보 리스트만 갱신하며 교류 리스트는 변경하지 않습니다.

연산자 번호는 `번호 % 등록된 함수 수`로 순환시킵니다. 계산 결과에는 나머지 연산을 적용하지 않고 그대로 반환하므로 `2`나 음수도 저장할 수 있습니다. 계산 연산자 목록이 비어 있으면 안내를 출력하고 교류를 종료합니다.

## 현재 구현의 경계

- 교류 리스트의 네 값이 맡는 역할과 시작 교류의 선택은 고정되어 있습니다.
- 리스트는 비트만 저장하는 구조가 아닙니다. 위치를 나타내는 정수도 함께 저장합니다.
- 연산자 번호의 순환과 빈 목록 처리는 있지만, 정보의 길이·자료형·주소 범위를 모두 검증하지는 않습니다. 잘못된 위치를 넣으면 오류가 날 수 있습니다.
- `operator.py`는 Python 표준 모듈과 이름이 같습니다. 실행 파일은 경로를 지정해 우리 파일을 불러오지만, 다른 라이브러리를 추가할 때 이름 충돌에 주의해야 합니다.
- 정보 변수의 이름을 동적으로 읽는 기능, 지속 저장, 학습 평가와 갱신 규칙은 아직 없습니다.

## 변경 관리

기능을 작게 나누어 변경하고, 실행 결과를 확인한 뒤 Git에 기록합니다. 캐시와 가상환경, 로컬 환경 설정 파일은 `.gitignore`로 제외합니다. 동작이나 정보 배치가 바뀌면 위 설명과 예상 출력도 함께 갱신합니다.
